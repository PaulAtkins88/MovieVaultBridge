# MovieVaultBridge Code of Conduct

This project expects a professional, respectful contribution environment.

## Expected behavior

- Be direct and constructive.
- Focus criticism on code, behavior, and decisions, not people.
- Assume good intent until facts show otherwise.
- Respect the safety-sensitive nature of filesystem and copy behavior.
- Document changes clearly so others can review them efficiently.

## Unacceptable behavior

- Harassment, intimidation, or personal attacks.
- Discriminatory or abusive language.
- Deliberately misleading review notes or bug reports.
- Publishing private filesystem details, secrets, or sensitive logs without consent.
- Pressuring maintainers to bypass safety gates for risky copy behavior.

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates this code of conduct and may suspend contributors who repeatedly ignore it.
