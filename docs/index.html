MovieVaultBridge

Bridge a messy movie source into a curated vault with review-first safety.

MovieVaultBridge scans one library, compares it against another, flags uncertain matches, generates a dry-run plan, and only performs guarded copy operations when you explicitly allow it.

View on GitHub Read the docs
Why it exists
  • Recovered folders rarely match your target naming cleanly.
  • Blind file copies are too risky for curated media libraries.
  • Human review should guide ambiguous matches and upgrades.
  • Real writes should be gated, observable, and reversible where possible.

What it does

  • Scans source and target movie libraries
  • Caches the target inventory in SQLite
  • Uses metadata, title normalization, and year evidence
  • Separates copy-ready, review, and upgrade candidates
  • Persists review decisions for future runs
  • Tracks live copy progress and keeps the latest run report

Safety model

  • Dry-run first
  • Sandbox copy before real target copy
  • Explicit environment gates for copy execution
  • Typed confirmation phrase for real target writes
  • No overwrites for new-copy items
  • Explicit upgrade replacements only when approved
